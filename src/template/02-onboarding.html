把论文
写在 GitHub 上。

一个没有后端的 Overleaf 替代品。LaTeX 源码放在你自己的仓库里，每次保存都是一次提交；打开一个 HTML 文件，就能写作、预览、回到任意一版。

01

版本就是提交

不做私有格式的“云端文档”。仓库里只有 .tex、.bib 和图片，退出这个应用也能用 Git、Overleaf 或 arXiv 继续。

02

论文不经过第三方

浏览器直连 api.github.com。令牌只在本机加密保存，论文内容不经过任何中间服务器。

03

即时排版，真实 PDF

边写边看接近 LaTeX 的排版。需要最终稿时，GitHub Actions 用真正的 TeX Live 编译并提交 PDF。

新建私有仓库 · fine-grained token 指南 ·

OAuth 需要一个保管 client_secret 的服务器，而这不是这个项目的形态。GitHub 的 OAuth 令牌交换端点也不允许浏览器跨域调用。因此，唯一能保持“零后端”的方式，是你自己创建一个权限最小的 fine-grained token。

把 token 想象成一把只开一扇门的钥匙：只授权一个论文仓库、只给 Contents 读写；如果需要 Actions 编译 PDF，再给 Actions 读写。它不会进入仓库、不会出现在 URL 里，也不会被发送到 api.github.com 之外的任何地方。
